This repository contains the complete codebase, experimental data, and analysis for my Bachelor's thesis research.

Research Objective: 
To conduct a controlled, comparative evaluation of six Flutter state management solutions (Provider, Riverpod, BLoC, Adaptive BLoC, GetX, MobX) under identical experimental conditions, measuring CPU utilization, memory consumption, battery drain, and UI responsiveness (jank frames) under sustained high-frequency state updates.
